# Tsuzuki bootstrap

Tsuzuki is an experimental fork of Mihon focused on exploring a richer manga library and discovery experience.

## Upstream

The project tracks [mihonapp/mihon](https://github.com/mihonapp/mihon) as its primary upstream.

## Current status

Bootstrap only. No functional divergence or product rebranding has been introduced yet.

Planning for features, UX changes, architecture, and branding will be done before implementation.
