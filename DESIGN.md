# Tsuzuki design baseline

Tsuzuki remains manga-first: canonical work and chapter identity are separate from metadata and reading sources. The Reader uses quiet controls and keeps the current chapter and reading position central.

## Approved direction for Reader source discovery

Find/Add Reading Source is a temporary task, not navigation away from the reading session. Reuse the existing binding interaction without redesigning its visual language. Closing it and pressing Back once should return to the same chapter; searching or binding must not silently change reading progress or source preference. Library-origin title navigation keeps its existing behavior.

This file records the incumbent identity and this narrow approved direction; it does not authorize a broader visual redesign.
